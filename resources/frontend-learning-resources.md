# Frontend learning resources

Mostly free. Use them as lookups when a concept comes up, not as a reading list.
Links and course names may have moved: search by name if one is dead.

## Core references (use daily)
| Resource | Use it for |
|---|---|
| MDN Web Docs (developer.mozilla.org) | Reference for HTML, CSS, JS. Has "Quirks Mode and Standards Mode", the box model, `@layer`. Shows Baseline browser support. |
| web.dev/learn (Google) | Free structured courses: HTML, CSS, Accessibility, Performance, Forms. |
| caniuse.com and webstatus.dev | Check browser support before using a feature. |

## Learning courses
- web.dev Learn CSS and Learn HTML: modern, free, well ordered.
- The Odin Project (free): full path from HTML to JS projects.
- javascript.info: best free modern JS tutorial.
- Josh Comeau's blog and "CSS for JavaScript Developers" (course is paid, articles are free): explains why CSS behaves as it does.
- Kevin Powell (YouTube): practical CSS in short videos.

## Rendering, SSG, CSR, performance
- web.dev "Rendering on the Web": compares CSR, SSR, SSG with trade-offs.
- patterns.dev: rendering patterns, islands architecture, performance patterns.
- web.dev Learn Performance: Core Web Vitals and how to measure them.

## Accessibility
- WebAIM (webaim.org): contrast checker, WCAG checklist, screen-reader surveys.
- The A11y Project: checklist and practical guides.
- Inclusive Components (Heydon Pickering): accessible UI patterns.

## Design thinking and resilience
- Resilient Web Design (Jeremy Keith, free online): progressive enhancement.
- Piccalilli (Andy Bell) and Every Layout: CSS that scales without media-query piles.

## SEO
- Google Search Central docs (developers.google.com/search): read "SEO Starter Guide".
- web.dev SEO and Open Graph guides for link previews.

## Staying current
- Newsletters: CSS Weekly, Frontend Focus.
- Chrome for Developers blog; WebKit and Mozilla blogs.

## How to use them
1. When a concept appears in the work, look it up on MDN or web.dev, then write what you learned in LEARNING_LOG.md.
2. The spec (html.spec.whatwg.org) is accurate but dense: last resort.
3. Beware old tutorials: floats for layout, `<center>`, or jQuery for basics are out of date.
