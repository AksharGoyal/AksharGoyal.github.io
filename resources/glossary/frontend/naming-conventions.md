# Naming conventions

- **Numeronym** — abbreviation using a digit for the omitted letters: **a11y** (accessibility), **i18n** (internationalization), **l10n** (localization), **o11y** (observability), **k8s** (kubernetes).
  **Seen in:** npm package names — `@axe-core/a11y`, `i18next`. Job posts say "a11y experience required."
